# Super Déguè de Djéni

Site vitrine pour **Super Déguè de Djéni**, entreprise ivoirienne (Abidjan) de vente de dégué (lait fermenté et mil).

Construit avec React + Vite.

## Développement

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```

## Déploiement

Le site est automatiquement déployé sur GitHub Pages via GitHub Actions à chaque push sur `main`.
